# P061 — Azure Purview / Data Governance Cataloguing Exercise

This is a ready-to-use student starter package based on the provided exercise brief.

It contains:
- a step-by-step Purview procedure
- five synthetic sample datasets
- a classification mapping
- final-report template
- evidence checklist
- Mermaid architecture diagram

Important: this ZIP does not contain Azure credentials or pre-created cloud resources. You must connect/register your own permitted Azure sources and run the scans in your Azure/Microsoft Purview environment.

Start with:
`documentation/PROJECT_PROCEDURE.md`

Never commit passwords, access keys, connection strings, or other secrets.
